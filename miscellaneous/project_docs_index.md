# learnQT 项目文档入口

## 统一术语

| 术语 | 含义 |
| --- | --- |
| WorkspacePage / WorkspaceUi | 八页导航标识及 UI 状态；布局、搜索、资源目录和任务展示不属于场景 JSON。 |
| UI Thread | Qt 主线程；拥有 EditorController、对象树、属性面板、相机交互和显示上下文。 |
| Render Thread | 拥有活动 Scene 运行时及渲染上下文；消费版本化更新、运行积分器和正式任务。 |
| Render Queue Thread | 拥有任务快照对应的独立运行时与离屏上下文，串行正式出图；编辑线程可继续工作。 |
| Load Worker | 只准备 CPU 候选场景/资源；成功后提交，失败保留当前文档。 |
| Preview Denoiser | 独立 CPU OIDN 任务；只处理不可变图像快照，不访问 Scene 或 OpenGL。 |
| SceneDocument v2 | 可保存的资源、对象实例、组织树、材质、相机和设置；JSON ID 与 GPU 下标分离。 |
| BLAS / TLAS | 局部网格 BVH / 世界实例 BVH；组织组不参与空间变换。 |
| tile / 批次 | tile 是设置指定的矩形块；批次是在一个 GPU 安全边界前提交的有限数量 tile。 |
| 完整轮次 / spp | 所有像素各完成一次新采样，整图 FPS 按其实际完成时间计算。 |
| 历史帧 | `preRenderColorTex` 中最后一个完整采样轮次；暂停、停止和输出不混入未完成 tile。 |
| 显示桥 | TextureBuffer 的三槽共享纹理；GPU 完成与 UI 消费是两个条件。 |
| NEE / MIS / delta | 显式光源采样 / 多重重要性采样 / 使用概率质量的离散散射事件。 |

架构图区分 UI、加载任务、编辑渲染线程、正式队列线程、预览降噪任务和 GPU。资源预算是应用已分配资源的估算，不等于驱动报告的整块显存占用。
