# 九页工作区与界面

当前工作台采用 Qt 5 Widgets + Fusion 深蓝灰界面和亮蓝强调色。九个工作区共享同一个 EditorController、SceneDocument v2、GLWidget 和渲染线程；页面框架不是新的渲染引擎或商业资源库。本页记录 2026-09-09 的当前行为及本线程实际验证。

## 启动与通用操作

无参数启动建立空场景文档并默认显示欢迎首页，可在设置中关闭欢迎页。指定 `--scene`、`--model` 或回归入口时直接进入工作区。首次场景 CPU 准备仍在窗口构造前执行；首页不会提前初始化 GL，首次显示编辑视口时才创建共享上下文和 Render Thread。

左侧导航与工作区菜单通过 `navigateWorkspace(WorkspacePage)` 进入同一页面。右上角独立操作区提供开始渲染、暂停/继续和停止，不随编辑工具栏溢出而隐藏。窗口保留系统标题栏与缩放行为。

各页使用固定位置的面板，可以调整宽高、隐藏和恢复；不支持自由浮动或拖动重排。通过“面板”菜单重新显示当前页面板，通过“视图”恢复当前页布局，设置页可恢复全部默认布局。宽度小于 1450 时，除渲染页之外的底部区域自动隐藏；仍可用面板菜单展开。默认设计尺寸为 1600×900，已验证实际 1366×768 窗口。

切页保存布局并取消未完成的变换拖动，不重设 GLWidget 父级、不重建渲染线程、不增加文档 dirty 或 undo 记录。视口实际像素尺寸改变时仍会重新累积采样。首页、资源、设置、结果页隐藏编辑预览；正式任务继续运行。

## 各页功能与边界

| 页面 | 当前可用内容 | 尚未开放 |
| --- | --- | --- |
| 首页 | 欢迎区、新建/打开、进入预设浏览、真实最近项目、内置场景、快速开始说明。双击场景卡片打开；新建/打开成功后进入场景页。 | 教程、社区、更新动态；不提供账号或虚构项目。 |
| 场景 | 中央视口、对象树、性能和对象属性、底部资源浏览器。保留搜索、多选、分组、拖放排序、复制/删除、隐藏/锁定、变换、吸附及撤销重做。 | 独立渲染可见性、投影/接影和对齐等新增编辑能力没有接入。 |
| 材质 | 左侧“所选对象材质 / 全部场景材质”与搜索；中央真实场景预览；右侧基础参数、六类贴图和高级参数；底部节点结构示意。 | 独立实时材质球、通用材质库、可编辑节点及连线。 |
| 灯光 | 场景灯光列表与属性联动，新增/删除太阳盘或球形光，编辑名称、位置或方向、RGB 辐亮度、半径或太阳半角。 | 专用矩形灯、聚光灯、IES、色温及灯光预设。现有辐亮度不标作 lux。 |
| 相机 | 当前单相机的位置、目标、垂直 FOV，定位所选；与视口和撤销双向同步，并沿用场景保存。 | 多相机、传感器/焦距模型、景深、运动和构图辅助。 |
| 环境 | 本地 HDR 浏览、应用/选择/清除、启用、强度和旋转，保留底部资源条。 | 物理天空、云、雾、独立背景及背景可见性。 |
| 渲染 | 正式输出和交互预览设置、色彩管理、结果空状态、适应窗口/1:1/缩放/平移、上次完成结果、PNG/JPEG 导出、当前单任务表。 | 队列、跨会话历史、AOV、EXR、动画、自适应采样及降噪前后对比。 |
| 资源 | 内置场景与当前文档的模型、材质、纹理、HDR；分类、搜索、卡片与来源详情。打开场景、导入模型、应用 HDR 或定位引用。 | 在线库、收藏和直接拖放赋材质。 |
| 设置 | 欢迎页、工具提示、状态栏、最近文件数量、恢复布局、吸附步长和快捷键说明。 | 自动保存、插件、语言/主题切换、GPU 选择及缓存预算。路径区说明当前文件选择流程，不提供全局路径重定向。 |

材质浏览不替换对象绑定。未属于当前可编辑选择的材质只读，可用“选择使用此材质的对象”定位使用者后编辑；实际修改继续遵循现有材质作用域和共享材质按需复制规则。锁定对象仍不可修改。相机页拒绝位置与目标重合、或观察方向平行于上方向的输入。

资源浏览器共用目录模型，各自保留搜索条件；只有目录签名变化才重建列表。纹理使用可读取图片的缩略图，其他资源使用类型图标；没有将参考效果图中的别墅或材质球作为真实资源。HDR 列表来自本地资源目录及当前环境路径。

“从预设创建”目前进入资源浏览器，随后执行现有打开场景流程；它不是模板复制或另存未命名文档的独立工作流。材质节点是不可操作的示意图，未开放按钮均明确标注，不会模拟成功。

## 状态归属与持久化

- `WorkspacePage` 定义九页标识，`WorkspaceUi` 持有页面面板、导航状态、资源目录和任务展示记录；不访问或修改渲染线程拥有的活动 Scene。
- QSettings 使用 `workspaceV4/` 存储每页布局及本机偏好。旧 `docksV3` 不恢复到新工作区；窗口几何仍使用 `geometry`。页面布局切换时在内存保存，正常关闭时写入磁盘；其他偏好修改即时写入。
- 最近项目只记录成功打开/保存的真实场景路径，大小写不敏感去重，默认 12 项，可设 1–50。不存在的文件标注不可用，加载失败保留原场景。
- SceneDocument 保持 v2，单相机和既有 output/render/environment/display 字段不变；布局、最近文件、搜索、吸附偏好、演示节点和任务历史不写入场景。
- 正式任务启动前若 GL 尚未初始化，保留一次请求并等待就绪；重复点击不创建多份任务。准备、渲染、暂停和降噪时允许浏览页面，但禁用场景/相机/参数修改及资源应用操作。
- 任务表记录请求的输出尺寸与采样目标；终态冻结采样和耗时。恢复预览后收到的 RenderStats 不覆盖已完成任务元数据，渲染页状态栏也使用任务记录。
- 回归入口在测试输出目录下使用 INI，构造 QSettings 时明确使用所选格式，避免读取个人旧布局或写入个人偏好。`--cold-home` 只用于工作区回归，验证首页不初始化 GL 及首次渲染请求保留。

实现入口见 [代码地图](./module_map.md)，渲染线程安全边界见 [渲染流程](./render_flow.md)。隐藏全幅页的最小高度不再施加给编辑视口，窄属性表单自动换行，避免 Qt 将请求的 1366×768 窗口撑高。

## 表面精度修复的提交范围

同一工作区还包含此前完成的 GPU 修复，已纳入本次提交范围：实例与兼容求交使用共享的射线投影边函数，命中点按重心权重在三角形表面重建，非法平滑/贴图法线回退到朝向几何法线。GPU 回归新增 island 边缘夹具、共享边/顶点、真实缝隙、退化/平行射线、96 条长射线以及镜像掠射法线案例。

这些修复与九页 UI 分属不同模块，不改变现有 NEE/MIS 测度、RayEpsilon 公式或介质内外判定。它们不等于实现穿过折射界面的光照连接，也不能作为所有极端尺度、所有模型或其他 GPU 均正确的证明。具体实现和后续项见 [实现逻辑](./logic_overview.md)、[直接光采样](./direct_lighting.md) 和 [待办](./to-do.md)。

## 2026-09-09 验收

环境为 Windows、Qt 5.15.2、MSVC Release 和 OIDN 2.3.3。本线程基于 `6de78ca` 的工作区继续实现；提交还包含开始时已有的界面及表面精度改动。记录与最终相关源文件哈希见 [验收汇总](./validation/workspace_ui_2026-09-09.json)。

实际执行过：

```powershell
cmake -S . -B build
cmake --build build --config Release -- /clp:ErrorsOnly
ctest --test-dir build -C Release --output-on-failure

# 最终 UI 修正后的定向复测
ctest --test-dir build -C Release --output-on-failure -R 'scene_ui_switch_regression|workbench_ui_and_render_job|preview_interaction_regression'
```

- 全量 CTest **18/18 通过，387.12 秒**，包含新增工作区测试以及已扩展的 GPU 求交测试。此后仍有 UI 修正，该结果属于较早时点，不冒充最终代码整套重跑。
- 最终 Release 构建通过；最后的场景切换、编辑/正式任务和预览交互定向测试 **3/3 通过，86.89 秒**。
- 最终扩展工作区回归在 100%、150%、200% DPI 下分别通过，均使用 `--cold-home`，覆盖九页、真实场景、冷启动、文档/undo 不变、只读材质、相机/灯光/HDR 操作与撤销、搜索/布局恢复、跨页暂停/继续/停止、完成任务元数据、PNG/JPEG、偏好落盘和右上角按钮可见性。
- 三档均验证实际 **1366×768**，另有 1600×900 和请求 1920×1080 的截图。200% 下较大窗口受系统工作区限制，最终报告记录为 1920×1065；不能将请求尺寸当作实际尺寸。
- 已检查九页及窄窗口实际截图；渲染结果回归使用小尺寸、低 spp 输出验证生命周期，不作为画质或性能基准。

DPI 复现命令如下，三个 case 均实际执行过：

```powershell
$env:PATH = 'C:\Qt\5.15.2\msvc2019_64\bin;' + $env:PATH
$env:QT_SCALE_FACTOR = '1'
$env:QT_AUTO_SCREEN_SCALE_FACTOR = '0'
foreach ($case in @(@('1','100'), @('1.5','150'), @('2','200'))) {
    $env:QT_SCREEN_SCALE_FACTORS = $case[0]
    $resultDirectory = 'build/workspace-dpi' + $case[1]
    & .\build\Release\learnQT.exe --workspace-regression $resultDirectory --cold-home *> ($resultDirectory + '.log')
    if ($LASTEXITCODE -ne 0) { throw ('DPI regression failed: ' + $case[1]) }
}
```

截图和原始日志位于未版本化的 `build/workspace-dpi100/`、`build/workspace-dpi150/`、`build/workspace-dpi200/`；九页概览为 `build/workspace-overview.jpg`。每个目录的 `report.json` 包含最终结果与实际尺寸；早期失败截图或 CTest 的旧失败列表不代表最后一次运行结果。
