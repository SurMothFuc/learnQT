历史工作台阶段从 `master` 创建 `codex/scene-editor-workbench`，已有工作区、工具、场景和约 2.14 GB 导入资源先保存在 `3148f92`（`chore: snapshot workspace before scene editor redesign`）。本专题说明当前工作台及 v2 文档，并保留该阶段的实例渲染、交互修复与性能记录。2026-09-30 的八页界面操作及验证见 [工作区专题](./workspace_ui.md)；页面重组没有升级场景文件版本，也不是完整商业渲染器功能承诺。

## 工作台操作

无参数启动先建立空文档，默认显示欢迎首页；关闭欢迎偏好后进入场景页。“新建”确认未保存修改后建立空场景并进入场景页。菜单支持打开、保存/另存为、导入、指定缩放导入及便携包；预设入口保留。普通导入和文件拖入支持 OBJ/glTF/GLB/FBX，保留源尺寸、源节点变换并追加到当前选中组，整批失败不改变场景。CLI `--model` 的独立场景适配入口保留。

对象树支持搜索、多选、组层级、拖动换组与同级排序。根只能改名、建子组或导入；普通组可解散并提升内容，或单独选择连内容删除。模型支持改名、复制、删除、隐藏和锁定；锁定模型不可变换、改材质或删除。组织操作不改变世界位置。

| 操作 | 输入 |
| --- | --- |
| 选择 / 追加或切换 | 左键 / Ctrl+左键；树中另支持 Shift 范围选择。 |
| 相机 | Alt+左键环绕，中键平移，滚轮比例缩放，F 定位所选。 |
| 工具 | Q 选择、W 平移、E 旋转、R 缩放；Esc 取消拖动。 |
| 编辑 | Delete 删除、Ctrl+D 复制、Ctrl+Z 撤销；输入控件保留文本快捷键。 |
| 轴与吸附 | 单选世界/局部轴，多选世界轴；默认不吸附，步长移动 0.1、旋转 15°、缩放 10%。 |

选择模型有橙色轮廓和轻微覆盖色，活动对象更亮，包围框与中心操纵器始终位于显示叠加层。旋转方向和连续滚轮穿越中心的问题已修复。树、视口和属性面板共享选择与 undo；多选材质混合值只修改实际编辑字段，共享材质按需复制。六类现有纹理槽可查看、更换和清除。

Fusion 深蓝灰界面提供首页、场景、材质、照明、相机、渲染、资源、设置八页。顶栏只保留文件／撤销重做；变换、轴、吸附与预览入口在视口。渲染页分构图与提交／结果与队列；底部面板及渲染菜单保留队列控制。固定分区支持尺寸调整、隐藏和恢复；页面共享编辑 GLWidget，结果使用 ResultView，切页不创建编辑场景副本。

材质页浏览现有场景材质并明确只读原因及编辑作用域；场景页保留摘要与跳转。相机页管理已保存相机，构图草稿不覆盖来源。照明标签切换 sphere/sun 与 HDR，HDR 浏览不重复。首页／资源展示真实预设和引用资源；节点、景深等尚未实现。见 [八页工作区](./workspace_ui.md)。

## v2 保存格式

| 字段 | 内容 |
| --- | --- |
| `version/name/portable/credits` | v2、场景名、便携访问限制和来源。 |
| `models` | 外部资源 ID、路径、源材料绑定、导入选项/依赖、是否已展开。 |
| `objects` | 实例 ID、name、model、mesh、material、世界 transform、parent/order、visible/locked。 |
| `groups` | 组织组 ID/name/parent/order；唯一根 ID 为 `root`。 |
| `materials/textures/lights/hdr` | 材质、纹理槽/UV/sampler、sphere/sun 及 HDR。 |
| `camera/cameras/activeCameraId/render` | 兼容相机、已保存相机列表／当前 ID、轨道/FOV、预览 AA/降噪/尺寸模式/分块/反弹/采样上限、sampleSeed 和 rrMinDepth 等。 |
| `environment/display` | 环境强度/旋转，曝光及 tone mapping。 |
| `output` | 正式输出宽高、采样、tile、反弹、降噪、sampleSeed 和 rrMinDepth。 |

读取 v1 时在内存迁移并展开源节点，保持旧材质和取景；保存写 v2，原文件不自动升级。矩阵沿用行主序。GPU 缓存、选择和采样历史不写场景；八页及渲染两模式布局使用 workspaceV5/layout/ 和状态版本 5，其他应用偏好继续 V4。旧几何布局不直接恢复。

便携包保留依赖闭包、SHA-256 分目录、路径别名、禁止越界/原路径回退、临时目录验证后发布和 QSaveFile 原子保存约定。详见 [纹理与场景兼容性](./texture_scene_v1.md)。

## 实例、预览与正式任务

每份唯一网格建立局部 BLAS，实例使用矩阵、逆矩阵与材质引用，TLAS 管理世界包围盒。GPU 几何、材质、实例和 surface/PDF 分表。变换期间 refit，结束重建 TLAS；已有 BLAS 重建数和几何上传量为零。发光实例同步世界面积及选择 PDF，共用网格的不同实例不会混淆。

GPU 表面求交已共用沿射线投影的边函数，命中点按重心权重重建；掠射时不合法的着色法线回退到朝向几何法线，支持边界见 [实现逻辑](./logic_overview.md)。GPU 遍历使用近节点优先、进入距离栈和缓存逆方向；TLAS 使用 BLAS 遍历代价加权 SAH。阴影只加载必要材质数据；仍保留透明与介质的逐段透射率语义。

预览采用有界批量提交、每批资源绑定、约 16 ms 合成、三槽消费保护。小块不会被偷偷放大，块 FPS 仍统计实际 tile 完成数。Camera 小块的 GPU 执行效率损失还存在；较大块通常更高效，但单块耗时与交互响应需要权衡，约 8 ms 的批次预算不是硬上限。

正式输出默认 1920×1080、256 spp、128×128 tile、8 次反弹，独立于窗口。会话队列捕获文档、相机及输出快照，由独立 RenderQueueThread 串行渲染，允许继续编辑并临时光栅化预览。暂停／停止保留完整轮次语义，历史结果固定浏览，终态元数据不被预览覆盖。PNG／JPEG 输出不透明且无编辑叠加，JPEG 质量 95。旧直接正式任务回归路径仍保留编辑锁定。

新场景默认 ACES 近似、曝光 0、环境强度 1、旋转 0°；v1 旧曲线保留。OIDN 在线性 HDR 上运行，法线恢复 `[-1,1]`、albedo 线性；预览后台过滤并拒绝旧版本/旧尺寸，正式任务最终轮次过滤且支持取消。

## 2026-09-06 渲染基础修复与验收范围

- 空场景停止无意义重复计算/降噪；预览 OIDN 不再造成每 100 spp 的同步停顿。

- 场景、对象树、GPU 求交、纹理、灯光、正式任务、显示桥和转换工具均有自动回归；具体本轮命令和结果见下方验收记录。

## 当前边界

像素 AA 和三路辅助累积已实现，关闭 AA 保留中心射线；固定维度 Sobol/数字移位与 seed 已贯通，尚无通用重建滤波。预览与正式分别提供 RR 起始深度控件，seed 通过 JSON/开发 CLI 设置；默认 seed 0、RR 深度 3，加入队列冻结各自配置。实时 GPU 降噪与 GL 4.3 compute 已实现，能力不足仍回退 fragment。

### 分块优化测量

Camera 预设向上滚轮 9 格近景，**2848×1782 实际像素、4 次反弹、OIDN 关闭、预热 2 spp 后测量 32 spp**。正反顺序各一次；优化前是本轮已优化 BVH 的工作台副本，不是旧 master。离屏测量含批次 fence，排除加载、QWidget 显示桥和 OIDN。

| 模式 | 整图 FPS | 32 spp 提交批次数 | 合成次数 |
| --- | ---: | ---: | ---: |
| 优化前，100×100 | 2.670 / 2.682 | 16704 / 16704 | 16704 / 16704 |
| 优化后，100×100 | 3.595 / 3.607 | 3934 / 3891 | 464 / 455 |
| 优化后，400×400 | 5.264 | 1280 | 289 |
| 优化后，整图 | 5.256 | 32 | 32 |
