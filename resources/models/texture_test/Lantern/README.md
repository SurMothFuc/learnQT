# Lantern texture test asset

`Lantern.glb` is the binary glTF variant of the Khronos glTF Sample Assets
"Lantern" model. It validates embedded image decoding plus base-color,
metallic-roughness, normal, and emissive texture sampling.

- Source: https://github.com/KhronosGroup/glTF-Sample-Assets/tree/main/Models/Lantern
- Downloaded variant: `glTF-Binary/Lantern.glb`
